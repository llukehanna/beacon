## Actions

Every write is one of these named actions, run in one transaction. Parameters are checked against the declarations below before the handler runs: a missing required parameter, an unknown parameter or a wrong type is refused, an object parameter must name an existing object of that type, a string is at most 2,000 characters, and a list holds at most 50 strings of at most 200 characters. Rules that depend on an object's state (for example that a rule is pending before it can be approved) are enforced inside each handler and are not declared here.
