# Evaluation against synthetic ground truth

Beacon's agent reads each firm's source records, keeps only values it can quote, reconciles what the sources say, and scores the firm with the rubric. This page measures that work. The universe is generated, so every firm has a hidden true value for every axis and the agent's output can be checked exactly. Every figure below is measured against synthetic ground truth. None of them says how the agent would do on real firms.

Generated by `npm run eval` (never edited by hand). The same figures are in [evals.json](evals.json).

| Item | Value |

| Recorded values that passed grounding | 6,455 of 6,472 (99.7%) |
| Result | all thresholds met |

The extraction is read from the committed recordings, so the run needs no network and gives the same figures every time. The grounding row counts recorded answers whose quote is in the source record and contains the value as a word or substring. It says whether an answer quotes its record faithfully, not whether the value is right: the records include each provider's deliberate errors, which the sections below score against the truth.

## Tier agreement

Against synthetic ground truth: 52.4% of firms get the same tier from the agent's settled values as from the true values. Axes the agent abstained on or left in conflict count as unknown, so this is the tier before an analyst finishes the enrichment.

## Rule recovery

Against synthetic ground truth. The seed's rejection patterns are planted in memory (small firms, generalists, small deals, low deal volume, plus rejections that no screening rule can express) and the heuristic clusterer proposes screening rules from them. It recovered 4 of 4 planted patterns. This clusterer matches rationale wording and firm facts against a fixed list of candidate rules, so the figure checks the learning loop end to end; it does not measure open-ended discovery. The patterns, selection rules and wording are the seed's, planted into the bare generated universe with this run's own value stream, so the exact firms and values differ from the seeded database.

## Limits

- The universe, the sources and their errors are generated. The figures say the pipeline does what it should on this data, not how it would do on real firms.
- Precision counts a numeric reading in the right rubric band as correct, even when the figure itself differs.
- Grounding is a word or substring match. It confirms the quote is verbatim in the record and contains the value, not which axis the quoted sentence is about.

## Reproduce

```
npm run eval            # regenerate docs/evals.md and docs/evals.json
npm run eval -- --check # exit non-zero if a threshold fails or the committed files are stale
```
